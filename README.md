# מאפיית דנה: מסיפור לגרף

מערכת הזמנות למאפייה, בנויה כגרף LangGraph. הפרויקט הוא מטלת בית בקורס סוכני AI.

- [`prompt.md`](prompt.md): המפרט הטכני שממנו נבנתה המחברת, כולל שרטוט הגרף ורשימת הגרסאות והשינויים.
- [`dana_bakery.ipynb`](dana_bakery.ipynb): המחברת, עם ציור הגרף ו־15 הזמנות בדיקה שעוברות בכל המסלולים.
- [פתיחה ב־Google Colab](https://colab.research.google.com/github/esteravraham/dana-bakery-langgraph/blob/main/dana_bakery.ipynb)

המחברת רצה מ־session נקי של Colab, בלי API key ובלי קריאות ל־LLM.
